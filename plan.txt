# PLAN.md

# Mutual Location Sharing Application
**Version:** 1.0

---

# Project Goal

Build a lightweight, privacy-focused mutual location sharing application for Android.

The application is **NOT** intended for surveillance.

Every user must explicitly agree to share their own location before another user can see it.

Primary users:
- Couples
- Family members
- Close friends

The backend must be scalable enough to support thousands of users while remaining lightweight.

# AI Development Instructions

When generating code, follow these rules:

1. Always generate production-ready code.
2. Follow Clean Architecture.
3. Use dependency injection.
4. Never hardcode secrets.
5. Include comments only when necessary.
6. Return proper HTTP status codes.
7. Validate all incoming requests.
8. Use transactions where required.
9. Write modular code.
10. Include unit tests where applicable.
11. Use Swagger annotations for every endpoint.
12. Support Docker deployment.
13. Use environment variables for configuration.
14. Write reusable services.
15. Prefer interfaces for repositories and services.
16. Handle errors explicitly and return structured error responses.
17. Keep business logic out of HTTP handlers.
18. Make APIs backward-compatible through versioning (`/api/v1`).
19. Use UTC timestamps internally and ISO 8601 format in API responses.
20. Design database schemas with future scalability in mind (indexes, foreign keys, soft deletes where appropriate).

# Long-Term Vision

The architecture should eventually support:

- 100,000+ users
- Horizontal scaling
- Kubernetes deployment
- Redis caching
- Message queue (NATS or RabbitMQ)
- Push notifications
- End-to-end encrypted location sharing (optional)
- Self-hosted map tiles
- Web dashboard
- iOS application
- Public API for third-party integrations

The system should remain modular so components (authentication, location service, notification service, realtime service) can later be separated into independent services if growth requires it, while starting as a well-structured Go monolith.
